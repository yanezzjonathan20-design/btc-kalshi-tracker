# BTC Kalshi Tracker

Live Safari tracker for BTC 15-minute Kalshi contracts.

## Live version

[![Deploy live tracker to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/yanezzjonathan20-design/btc-kalshi-tracker/tree/main/cloudflare)

Cloudflare's Workers platform supports importing a GitHub repository and automatically deploying the Worker; the deployed `workers.dev` URL serves the tracker and backend from the same origin.

The GitHub Pages version remains available as a fallback.
